# Cygnus 4.5.2 Release-Note Coverage Audit

Reviewed on 2026-10-25 against the final **Stellaris 4.5.2 released [checksum 9776]**
announcement dated 2026-10-06 in the
[official Steam announcements](https://steamcommunity.com/app/281990/announcements/?l=english).
The adjacent October 1 tentative notes and 4.6 previews are not this pack's authority.

## Coverage decision

This is a compact, additive release-note pack, not a self-contained snapshot. It covers
the advice-changing rules for equipment preferences and upkeep, reserve conservation,
Virtual automation and growth, Cybernetics, Covenants, subjugation and revolts, and
Nomadic Knights. It retains the 4.5 population/faction guidance and 4.5.1 combat and
automation corrections. Cosmetic changes, performance fixes, modding APIs, isolated
event fixes, and granular component tuning are omitted.

The pack deliberately avoids deriving unannounced numerical rules or treating eligibility
as guaranteed diplomatic acceptance. Existing campaign facts, active DLC, and modded
behavior retain precedence. The loader reports **partial**, through **4.5.2**; older
saves do not receive these additions, and unknown later release lines receive no pack.

## Delivery and regression checks

- In-app Advisor and MCP Advisor Briefing use the same question-based selection.
- Rule-label and body matching cover branch-office costs and combat disengagement even
  when the question does not match a heading. Weak incidental matches are filtered.
- Explicit `supersedes-rule` directives replace individual older rules. The existing
  Pegasus reserve-conversion correction exercises this without dropping other logistics facts.
- Snapshot selection respects the requested version and the latest breaking boundary.
  Future, empty, and unreadable snapshots cannot reintroduce Pegasus into earlier Cygnus saves.
- MCP exposes coverage metadata and the complete selected prompt outside briefing compaction,
  including a separate text block for clients that do not consume structured output.
- `tests/test_game_knowledge.py`, `tests/test_patch_loading.py`,
  `tests/test_companion_dlc_context.py`, and `tests/test_mcp_context.py` cover these contracts.
- `scripts/experiments/eval_game_knowledge.py --suite cygnus` records semantic cases for
  separate provider/human review. Deterministic tests are not a substitute for that review.

## Remaining validation

The installed game examined for this audit is Pegasus 4.4.6 (fdde). The available save
metadata contains 20 Corvus 4.2.4 saves, one Cetus 4.3.0 save, and one Pegasus 4.4.6
save. No Cygnus save or shipped Cygnus data was available. Do not advertise validated
4.5.2 ingestion, faction headcounts, or complete mechanics coverage on this evidence.

Before promoting this line to a snapshot, check each numerical claim against shipped
stable Cygnus data, validate population/faction representation and active policy IDs
against a real save, and save a reviewed QA baseline. Keep the earlier-save boundary
regressions when adding that snapshot.
